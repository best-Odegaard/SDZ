📖 算法说明

组队匹配：J(A, B) = |A ∩ B| / |A ∪ B|  →  综合评分 = 技能×0.5 + 兴趣×0.3 + 共同收藏×0.2

队友匹配：同上，过滤匹配度 < 20 分的结果，按分数降序排列

当前测试数据：用户1(张三) 技能=前端,后端,算法 | 用户2(李四) 技能=算法,设计,文案 | 用户3(王五) 技能=硬件,嵌入式,算法
