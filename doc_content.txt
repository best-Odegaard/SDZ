赛搭子——用户操作手册
一、系统概述
赛搭子是一款面向高校师生的赛事信息聚合与组队微信小程序，平台以 “找赛事・搭队友” 为核心定位，一站式实现赛事浏览、报名时间查询、组队需求发布与匹配、简历投递筛选、校园赛事交流发帖等操作，页面可视化呈现，操作流程简洁直观，有效解决高校学生赛事信息获取困难、组队盲目、竞赛交流渠道缺失等问题。
核心价值
系统遵循信息聚合、精准匹配、及时触达的设计原则，依托智能推荐算法实现参赛人员精准匹配，同步支持校内、全国两类赛事信息展示。赛事浏览、收藏等基础操作采用同步处理，交互响应实时；智能组队匹配、简历解析等计算逻辑由 Spring Boot 后端统一承载，单机部署即可满足全校师生使用需求，无需独立部署算法服务，兼顾用户使用体验与系统运行性能。组队模块增设简历互发功能，实现参赛队友规范化筛选。
创新点
双轨赛事信息聚合：校内赛事、全国赛事分设 Tab 切换展示，填补校内赛事统一聚合展示的市场空白；校内赛事由管理员通过后台手动录入，无需对接校方官方数据接口。
智能组队标签匹配：基于技能标签相似度算法，自动推送适配参赛队友。
简历双向互审机制：组队双方可互相发送、在线预览简历，规范化组队筛选流程。
报名时间智能提醒：支持赛事订阅，在报名关键节点自动推送提醒消息，依托 SpringBoot 内置定时任务完成消息调度，无需部署 Redis 分布式定时组件。
赛事日历可视化：以日历视图直观展示报名时间安排，便于合理规划参赛节奏，区分报名开始、截止、正式比赛三类时间节点。
6. 学院定向赛事筛选：校内赛事绑定对应学院标签，学生可快速筛选本院专属选拔赛、学科竞赛，适配多院系高校使用场景。
7. 多维度组队筛选体系：组队列表支持学院、专业、年级、赛事类型、技能标签多条件联合筛选，精准匹配同背景参赛伙伴。
8. 赛事难度分级推荐：管理员录入赛事时划分入门 / 进阶 / 高阶难度，新生可优先筛选低门槛校内竞赛；智能匹配同步结合赛事难度推荐适配队友。
9. 校内往届获奖成果库：赛事详情页展示本校往届获奖队伍、参赛作品简介，为在校学生提供备赛参考，打造本校专属竞赛资源阵地。
10.校园竞赛发帖社区：独立交流板块，支持图文发帖、单层评论、点赞互动，划分四类帖子分类，满足校内竞赛答疑、经验分享基础交流需求。
11.一键式闭环操作：从赛事浏览、设置提醒至发布 / 申请组队，整体操作步骤精简，实现全流程便捷操作。

三、核心操作步骤
步骤1：赛事浏览——校内、全国双Tab切换（校内赛事由管理员后台手动录入更新）
前置条件
已登录赛搭子小程序
网络连接正常
完整操作流程
进入小程序首页，顶部为双Tab切换栏——“校内”与“全国”；
点击【校内】Tab，展示本校发布的赛事：
· 数据来源：教务处、各学院、校级社团组织发布
· 赛事类型：校内学科竞赛、院级选拔赛、校园文化活动等
点击【全国】Tab，展示全国性赛事：
· 数据来源：官方赛事平台、主办方官网等公开信息聚合
    · 赛事类型：中国国际大学生创新大赛、“挑战杯”、ACM-ICPC、数学建模等
两个Tab下均支持【分类筛选】：
· 赛事类别：学科竞赛 / 创新创业 / 体育竞技 / 文艺活动 / 其他
    · 报名状态：报名中 / 未开始 / 已截止
点击任意赛事卡片，进入【赛事详情页】
步骤2：查看报名信息与复制报名官网地址
在赛事详情页找到【报名信息】区域
系统展示该赛事的报名方式说明，统一为一段文字描述，
例如：
· “登录全国大学生创业服务网在线报名，网址：cy.ncss.cn”
· “填写报名表提交至学院教务办公室，具体请留意班级群通知”
· “通过学校教务系统报名，路径：教务系统→实践管理→赛事报名”
如文字中包含网址，用户长按文字区域，弹出【复制】选项，点击即可复制网址；
复制后，用户自行打开浏览器粘贴访问，进入官方报名页面完成报名。

6. 已设置提醒的赛事可在【我的】→【提醒管理】中查看、修改或取消提醒。

1.两层架构
2.核心流程
（1）校内/全国双轨赛事浏览流程
用户进入首页 → 默认展示【校内】Tab → 点击【全国】Tab切换 → 分别请求不同数据源接口 → 展示对应赛事列表 → 点击卡片查看详情（含报名方式说明）
（2）报名提醒流程
用户设置提醒 → 选择提醒时间节点 → 数据库存储提醒记录 → 后端定时任务每分钟扫描即将到期提醒 → 到达触发时间 → 调用微信模板消息接口 → 用户收到提醒
（3）组队申请与简历发送流程
用户点击申请加入 → 判断是否要求简历 → 若要求，检测简历是否完整 → 提交申请 + 简历 → Java 后端存储数据 → 后端 Java 工具类计算双方技能匹配度 → 发布人收到申请通知 → 在【收到的简历】中查看与处理
（4）帖子发布流程用户进入社区→点击发帖→填写标题分类正文图片→提交发布→后端校验图片数量→保存帖子、图片路径到数据库→展示在社区列表与个人帖子
（5）点赞评论流程用户点赞 / 提交评论→后端更新点赞计数、新增评论记录→帖子实时刷新数据

七、常见问题与排查
问题1：校内Tab没有赛事数据
· 检查当前是否有已发布的校内赛事（初期可先录入少量示例数据）；
· 下拉刷新页面；
· 确认筛选条件未过滤掉所有赛事。
问题2：报名信息中没有网址
· 校内赛事通常无官网报名链接，报名方式以文字说明为主（如“提交报名表至辅导员处”）；
· 请按照报名方式文字说明中的指引完成报名；
· 如有疑问可联系赛事主办方（如教务处、学院）咨询。
问题3：报名网址无法直接点击跳转
· 赛搭子采用文字展示+长按复制的方式提供报名网址，不提供直接跳转；
· 用户需长按网址文字，点击【复制】后，自行打开浏览器粘贴访问；
· 此为产品设计选择，旨在明确平台定位——信息展示与组队服务，不承担报名职能。
问题4：设置了提醒但没有收到推送
· 确认提醒时间是否已到达；
· 检查微信小程序【订阅消息】设置是否允许接收消息；
· 检查【我的】→【提醒管理】中提醒设置是否仍为有效状态。
问题5：发送简历时提示“简历不完整”
· 检查简历中所有必填字段（姓名、学院专业、年级、技能标签、个人简介）是否已填写；
· 确认简历状态是否为“已完成”（草稿状态不可用于申请）。
问题6：智能匹配结果不准确
·  完善个人资料内技能标签、参赛兴趣标签，标签维度越丰富匹配精度越高；
·  多收藏目标赛事，优化算法对用户参赛偏好的判断依据。
问题 7：如何录入本校内赛事？
答：项目配套简易管理员后台，管理员输入账号密码登录后，可新增、修改、删除校内赛事，无需对接学校官方系统。
问题 8：系统部署硬件与存储要求
课程设计、实训演示场景可本地部署：后端 SpringBoot 项目搭配本地 MySQL 数据库，简历文件、帖子图片统一存储至本地文件夹。· 完善个人资料中的【技能标签】和【参赛兴趣】，标签越多匹配越精准；
· 多收藏感兴趣的赛事，帮助算法理解你的偏好方向。
问题 9：发帖上传图片失败
图片数量不超过 3 张；
开启微信文件权限，切换网络重试。
问题 10：帖子删除后评论仍可见
1.删除帖子会同步清空全部点赞、评论数据，下拉刷新页面即可。
八、操作总结——赛搭子·三步走
第一步：找赛事打开赛搭子 → 切换【校内】/【全国】Tab → 浏览赛事 → 收藏 + 设置报名提醒
第二步：看报名进入赛事详情 → 查看报名时间与报名方式说明 → 有网址则长按复制后前往浏览器访问 → 按说明完成报名
第三步：搭队友点击【找搭子】发布组队需求 → 或点击【看搭子】浏览组队列表 → 智能匹配推荐合适的赛搭子 → 申请加入 + 发送简历（如要求）→ 通过后一起参赛。
第四步：社区交流点击底部【社区】Tab，浏览各类竞赛经验帖；发布图文帖子提问或分享备赛心得，点赞评论和同学交流。
特别声明：赛搭子为赛事信息聚合与组队服务平台，仅提供赛事信息展示、报名时间提醒和组队撮合功能，不承担赛事报名职能。所有赛事的正式报名均需由用户自行通过主办方指定的官方渠道完成。平台展示的报名时间及报名方式均来源于公开信息或运营录入，仅供参考，请以主办方最新官方公告为准。
